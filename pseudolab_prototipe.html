MATERI SINGKAT

Apa itu IF–ELSE?

Dalam algoritma, IF–ELSE digunakan untuk memilih tindakan berdasarkan kondisi.

IF kondisi THEN
    aksi jika benar
ELSE
    aksi jika salah
ENDIF

Contoh: menentukan kelulusan

Jika nilai ujian 75 atau lebih, statusnya “Lulus”. Jika kurang dari 75, statusnya “Belum lulus”.

INPUT nilai
IF nilai >= 75 THEN
    OUTPUT "Lulus"
ELSE
    OUTPUT "Belum lulus"
ENDIF

Perhatikan operator >=: artinya lebih besar dari atau sama dengan.

LATIHAN INTERAKTIF

Tantangan 1: Pilih kondisi yang tepat

Sebuah sistem menampilkan “Lulus” jika nilai murid adalah 75 atau lebih. Kondisi mana yang tepat?

Tantangan 2: Uji pemahaman

Jika kondisi yang digunakan adalah nilai >= 75, apa hasilnya ketika nilai = 75?

0 / 2
